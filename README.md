# Act-1.3-Integradora

## Bienvenida en C++

Este proyecto contiene un programa simple en C++ que muestra un mensaje de bienvenida.

## Compilación y Ejecución

Para compilar el programa:
```bash
g++ -o bienvenida main.cpp
```

Para ejecutar el programa:
```bash
./bienvenida
```

## Salida Esperada
```
¡Bienvenida!
```
